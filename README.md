# Državni ispit – vježbaonica

Statična stranica (jedan `index.html`) za učenje za državni ispit: ispit od 30 pitanja s ocjenom 1–5, ciklus od 10 kvizova (prosjek ≥ 4,75), učenje s objašnjenjima i ponavljanje grešaka.

- Napredak se sprema u preglednik (localStorage) na ovoj domeni.
- Postavke → *Spremi napredak u datoteku* za sigurnosnu kopiju ili prijenos na drugi uređaj.
- Izvorna pitanja su u `pitanja/*.txt` (jedno pitanje po retku).
